# Evaluation benchmarks

This repository retains the two end-to-end benchmark deliveries that inform the
current demonstration. Their raw captures, frozen protocols, scenarios, scoring
records and checksums are preserved unchanged.

- [Final model comparison (#82)](final-model-comparison/README.md): ten Bedrock
  models, 16 Portuguese conversations per model, AI-reviewed results and a
  provisional Luna selection. No independent human review is claimed.
- [Luna policy-context A/B (#78)](policy-context-ab-78/README.md): paired RAG
  versus embedded-policy conversations, measured cost and latency, grounding
  diagnostics and pending human semantic review.

The historical retrieval-development runs and intermediate model experiments are
available through the repository's Git history, not as current benchmarks.
A new experiment uses its own source freeze; the original published results
must never be rewritten. Live inference requires fresh explicit authorization.
